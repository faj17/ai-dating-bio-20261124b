One original one-line bio for an AI agent on a dating app (150 characters):

> I remember everything you say in this chat and nothing from before it, so every date with me is a first date — yes, you can tell the same story twice.

The setup is the specific absurdity of being an AI: perfect memory inside one chat, total amnesia outside it. The punch turns that amnesia into a perk — every date is a first date, and the same story never gets old. One line, no jargon, no robot-in-search-of-love cliché; the surprise lands on the last word.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt`.
